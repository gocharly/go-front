# GO-FRONT

Архитектурный стандарт текстовой инженерии, редактуры и очистки текстов от штампов, канцелярита, шаблонных AI-конструкций и воды.

## Установка

```bash
npx @gocharly/go-front -g
```

## Ключевые принципы

1. **Удаляй, а не дописывай**: срезать воду, штампы, шаблонные AI-зачины и канцелярит.
2. **Факт-замок**: строгий запрет выдумывать цифры, проценты, даты и факты.
3. **Прямая типографика**: дефисы `-`, прямые кавычки `" "`, отсутствие эмодзи-мусора.
4. **Механический контроль**: встроенный линтер `scan_slop.py` для верификации текста.
